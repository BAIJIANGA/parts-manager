元器件物料管理系统  ——  桌面版 / 便携免安装
============================================

【怎么用】
  双击「元器件物料管理.exe」。

  就这样。不需要装 Python,不需要装任何东西,
  不会打开浏览器,不会弹命令行窗口,也没有任何联网行为。


【必须知道的一件事】
  请保持【整个文件夹】完整。
  exe 必须和 runtime、app 两个文件夹放在一起;只把 exe 单独拷走是跑不起来的。

  想换地方用?把整个「元器件物料管理」文件夹拷到 U 盘或别的电脑即可。
  目标电脑什么都不用装。


【先弄懂这 6 个词】
  整个系统就靠这 6 个数字说话,看懂它们,每一页都通了:

    现有   手上真正有多少个
    安全   你希望至少留多少个(低于它就会提示「偏低」)
    需求   在做的项目一共要用掉多少个
    缺口   = 需求 − 现有,不够的那部分(够了就不显示)
    在途   = 已经下单、还没到货的数量
    该买   = 目标 − 现有 − 在途        其中 目标 = max(需求, 安全)

  一句话:该买 = 把项目需求和安全库存都填满,再扣掉手上有的和路上有的。
  所以同一个东西不会让你重复买 —— 下过单,它就从「该买」里消失了。


【界面里有什么】(从左到右,就是一条使用动线)
  总览     一屏看全局:元件多少种、库存多少个、值多少钱、几种要买、几种缺货,
           下面接着是项目能不能开工、最近动了什么。
  库存     首页是「电阻 / 电容 / 电感 …」一张张大类卡片,一共 16 个标准大类,
           有没有货都列在那儿(没货的是灰的,写着「暂无库存」);
           点一张就进到那个大类的独立页面看具体型号,左上角「← 返回」回卡片首页。
           二级页面【只列有库存的元件】,库存为 0 的不出现,所以点进一个还没入过
           货的大类会是空的 —— 这是正常的。
           二级表横向排开就是:现有 / 安全 / 需求 / 缺口 / 在途 / 该买 / 状态。
           「丝印」那一列是给拆机料用的:小芯片上印的三个字母根本不是料号,
           记下来就能搜回去(搜「CX4R」能直接找到那颗芯片)。
           上方还有一排筛选:值 ≥ / 值 ≤ / 单位 / 封装。
           「我这个 0805 的抽屉里到底有没有 1k~10k 的」就靠它回答。
           值可以写 1k、10kΩ、0.1uF,也认纯数字。
           (导入 BOM 只是记下「这块板子要用到什么」,东西还没买回来,那不算库存,
            所以不会出现在这一页。)
  出入库   这一页**只查账,不开单**。分成【入库流水】和【出库流水】两张表,
           随时能回答「什么时候进了什么、什么时候出了什么」。
           选中一行可以撤销;已撤销的淡显但不会消失。

           项目下拉里只列**真的有该方向记录**的项目 —— 导入 BOM 建出来、
           一次库都没动过的项目不列(选它只会得到一张空表),藏了几个写在
           下面那行摘要里。

           盘点 / 移库不在这里,它们既不是进也不是出,请到「流水」页看。
           四种动作都留痕、都禁止负库存。

           ★ 真正的收料 / 发料在「项目 BOM」页里做。
  项目BOM  右边分三个页签:【BOM 明细】【元件入库】【元件出库】。
           左边选一个项目,右边三个页签都是这个项目的。

           ── BOM 明细 ──
           导入 BOM 自动建元件、算缺料。Altium 的 .xlsx 能导,
           KiCad / EasyEDA / 立创导出的 .csv 也能导 —— 列名中英文都认,
           编码和分隔符自动识别,不用先改格式。
           导入前会弹一个「核对品类」的窗口 —— 它只列**它拿不准的那些行**,
           每行都写着自己凭什么这么猜(比如「位号 C 说电容,值 10kΩ 说电阻,
           两条互相矛盾」)。扫一眼,要改的选中后下面下拉一选、点「应用」
           就批量改掉;双击一行是单独改。下拉里没有你要的词?**直接打字打进去**
           —— 那只是个建议清单,不是规定。(双击那种单行改法也一样能打字。)
           它拿得准的那些默认不显示 ——
           让你从头看一遍是不现实的,你只会直接点确定。想看全部就取消
           「只看要确认的」。改完点「确认导入」。
           「计划」是打算做几块,「能造」是照现在的库存最多能装出几块 ——
           它由最缺的那一行决定,所以看「缺料行」和红色的行就知道卡在哪。
           双击一行可以改单块用量、损耗率、固定损耗,以及标成
           【可选件】(缺了不影响能造几块)或【免点件】(螺丝、锡这类,算需求但
           不卡产能)。「替代料」里加的料,库存会算进这一行的可用量。
           缺料想买?点「缺料转采购」,只把还差的部分加进采购单。
           这一行和库里那颗料的写法对不上(仓里写 4.7kΩ、板上写 4.7k)?
           选中这一行点「找相似库存…」,按「值 + 封装」列几个最像的,
           并写明像在哪里。越像的排越前面,但**是不是同一颗要你自己确认**。
           ★ 点左边随便哪一行,右边就会出来这块料的详情:这条需求要多少、
           已经发了多少、还差多少,以及这颗元件本身的值 / 封装 / 立创编号 /
           厂家料号 / 现在有多少 / 分别放在哪个仓位。
           ★ **「品类」就在那块面板上,是个下拉框,能直接改。** 选一个按回车
           (或点「保存品类」)就立刻生效,明细、收料、出库三处一起跟着变。
           下拉里是内置清单加上你库里已经在用的词;认不出来的(光耦、传感器
           模块这些)就**直接打字填一个**,别将就着挑个最接近的 —— 填个不准的
           品类,以后按品类找料就找不到它。

            ── 元件入库 / 元件出库 ──
            真正的收料和发料在这里。每个方向有两种开单方式,默认「按 BOM」;
            「自由」那种是给不在 BOM 上的东西用的(螺丝、锡、随手补的料)。
            收料和发料都要记在项目名下,所以必须先选项目。
            下面就是这个项目在这个方向的记录,选中能撤销。

            ★ 按 BOM 收料(默认)——
            一行 = 一条 BOM 需求,不用自己回忆该收什么。一行专门有一列写着
            **品类**,值和封装对不上时靠它最后看一眼。数量**默认就是 BOM 的
            总需求**,不用自己算;双击一行能改。前面有可勾选的小框(点「选」
            那一列,或选中按空格),勾好了点「✓ 勾选的全部入库」,一次全收进来。
            ★ 货只到了一部分?**选中那一行,点「✓ 只入库选中这一行」。**
            按钮上会写明你选的是哪一行,点它就只收这一行 —— 不用先去把别处的勾
            清干净,再点一个写着「全部」的按钮。右键点那一行也有同一个动作。
            单个收和批量收走的是同一条路,收完**只清掉这一行**,别的勾还在,
            可以接着收下一行。
            注意:入库**不会**把 BOM 的「已发料」记上 ——
            货进仓库不等于发给板子了。

            ★ 按 BOM 出库(默认)——
            这是最有用的一屏。**库里 0603 有 8 个、0805 有 2 个,而 BOM 要 10 个**,
            这种事天天有。所以这里一个 BOM 需求是一行,前面有展开箭头,点开就是
            **库存里能凑它的料**:

                100nF   ×10  [还差 2]     ←「封装」那一列写着 0603
                  ☑ 100nF   封装 0603   库存 8  本次出库 8  还需要 2
                  ☐ 100nF   封装 0805   库存 2  本次出库    还需要 2

            名字只写值(100nF),封装单独占一列。万一这份 BOM 里真有两行同名
            不同封装(100nF 0603 和 100nF 0805),树列上会**自动补上封装**,
            免得两条需求看起来一模一样。

            勾一颗、填个数,**父行和同一行其它候选的「还需要」立刻就减**。
            上面那张图里勾掉 0603 那 8 个之后,0805 那行的「还需要」会自动变成 2,
            等于提醒你「再勾这颗、出 2 个就齐了」。默认数量填的是
            min(这颗的库存, 还差多少),多数时候连数字都不用敲。
            候选的排序来自「找相似」,**BOM 自己指定的那颗料只要还有库存就排
            最前面**(绿色的),BOM 里登记过的替代料也会列出来。库存里一颗都
            凑不出的需求照样列出来,展开写着「得先入库或设替代料」。
            懒得一个个勾就点「自动配齐」,它按相似度配一遍填好勾选,
            **但不会自己提交**,凑不齐的地方会留着让你看见。
            点确认前会把「要发哪几行、共几个」念一遍 ——
            出库是扣库存,看清楚了再点。
            出完的账记在这条 BOM 需求上,撤销其中一笔时它的「已发料」
            也会跟着退回去。

            ── 找相似 ──
            写法和库里对不上(仓里写 4.7kΩ、板上写 4.7k)?点「找相似…」,
            按「值 + 封装」列几个最像的,并写明像在哪里。越像的排越前面,
            但**是不是同一颗要你自己确认**。从 BOM 明细里挑中之后会自动切到
            「元件出库」、把「这条需求用这颗料顶」挂到分配树上勾好,接着出库就行。
  采购     上面是「该买什么」(算出来的,每一行都写了为什么),下面是「采购单」。
           流程:勾选该买的 →「把选中的加入采购单」(先记成「想买」)→ 真下过单了
           点「标记为已下单」(从这一刻起算在途)→ 到货了点「到货入库」。
           也可以只收一部分,剩下的继续算在途。
           「想买」不算在途,「已下单」才算 —— 这样不会把还没下单的东西当成
           已经在路上。
  仓位     仓位的增删改。支持 A柜 / 01层 / 02格 这样的层级:建的时候有个
           「只用来分层」的勾,勾上的(比如「A柜」「01层」)本身不装东西,防止
           东西被塞到一个其实没有物理位置的节点上。
           选中上层仓位时,右边会级联列出它下面所有仓位里的料。
           「盘点这个仓位…」是实物清点用的:拿一个抽屉,逐个输入实数、回车,
           自动跳到下一个,全程不用碰鼠标。只有和账面不一样的才留记录 ——
           对得上的不留,否则流水会被几百条「没变」淹掉。
           数不到的就填 0;没数的行保持原样不动,也可以只数一半先存着。
  流水     全部动作的记录,四种动作都在这里(入库 / 出库 / 盘点 / 移库)。
           撤销过的会淡显并标上「已撤销」,不会消失 ——
           历史要看得见,只是别再当它是有效的。选中任意一条可以单独撤销。

           和「出入库」页的分工:那一页只看进和出两个方向,这一页是全部 ——
           盘点 / 移库既不是进也不是出,只在这里看得到。

  常用操作在「工具」菜单里:备份数据库、按流水重建库存余额、导出 CSV、
           ↶ 撤销上一次出入库、🔍 查重与合并。
  元件列表里点右键可以直接开单(入库/出库/盘点/移库),双击一行是编辑。
  快捷键:Ctrl+I 快速入库,Ctrl+B 批量入库,Ctrl+Z 撤销上一次,F5 刷新全部。


【录错了怎么办:按 Ctrl+Z】
  这套东西是让你「收到货就立刻记一笔」的,好处是数据不会烂,代价是录错也变容易了
  —— 多按一个 0、选错仓位、把「出」按成「入」。所以留了一条退路。

  按 Ctrl+Z(或「工具」菜单里的「↶ 撤销上一次出入库」),它先把那一笔是什么
  摆出来给你看一眼,确认就退回去了。流水页里选中任意一条也能单独撤销,
  包括撤销某一次盘点。

  撤销**不会删掉记录**,而是补一笔反向流水,原记录标成「已撤销」。
  为什么非要这样:这套东西的地基是「流水只增不改、余额随时能按流水重建」,
  删一笔就再也重建不出来,而且事后查不出「那天到底是谁把它改成这样的」。
  撤销采购到货时,采购单的已收数量也会一起退回去,否则那张单永远收不完。


【库里长出重复料了:工具 → 🔍 查重与合并】
  BOM 是要反复导入的,而不同时期的 BOM 里同一个料可能一条带着立创编号、
  另一条只有值和封装 —— 于是库里长出两三条,库存还分散记在两处。
  这类毛病不会自己好,只会越来越难收拾,所以隔段时间扫一遍。

  它按「有多确定」分三档找:
        料号相同     → 硬证据,基本可以确定
        名称完全相同 → 一般是反复导入长出来的
        值+封装相同  → 只是可疑,得你自己确认(不同耐压的电容就长得一样)
  左边选一组,右边点一行选中「要保留的那一条」,再把其余的并过来。

  合并会这么处理:各仓位库存相加、BOM 里指向被并那些的行改指过来
  (同一个项目里会并成一行、用量相加、位号拼起来)、采购单和替代料一起改指。
  **出入库流水一条不动** —— 那是真实发生过的收发货,改了就不是历史了。
  被并掉的那条**不删**,只标上「已并入」,列表里不再出现;
  「已合并的元件…」按钮能查回「当初并到哪儿去了」。


【最该养成的习惯:收到货就记一笔】
  按 Ctrl+I(或者点「库存」页右上角的「⚡ 快速入库」),它只问你三件事:
  是什么、几个、放哪。搜得到就回车;搜不到也直接回车,**当场给你建一条新记录**
  (只填名字,封装 / 编号 / 丝印以后再补),它不会拦着你「先把东西记下来」。
  记完窗口不关,光标回到搜索框,接着录下一袋。

  为什么非要收货那一刻记:这类工具最常见的死法就是「攒一堆再补录」——
  一补录就要翻箱倒柜,翻两次人就不想用了,数据一烂整套系统就废了。
  收货时袋子还在手上,十几秒的事。

  顺带一提:常用的料在元件编辑里设一次「默认仓位」,以后入库就不用每次选仓位了。


【一次收到一整箱:批量入库(Ctrl+B)】
  一行一个料,数量写成 x50,比如:
        10k 0603 x50
        100nF 0805 x20
        STM32F103C8T6 x2
  也可以直接从 Excel 里复制粘贴(有制表符时,最后一列是数字就当数量)。
  注意:行尾光秃秃一个数字不算数量 —— 不然「100nF 0805」会被读成 805。

  点「解析预览」之后,每一行都会对到库里的一条元件上给你看:
        命中已有的(绿)  → 直接入库
        库里没有(绿)    → 按这个名字新建一个,归到「未分类」
        对上了好几条(黄)→ 它不会替你猜,需要你双击指定;不指定就跳过
  数量和匹配都能在预览表里改。确认没问题再点「全部入库」。
  批量操作最怕「猜错了还悄悄记进去」,所以这里宁可多停一步。


【数据在哪】
  data\parts.db        你的全部数据都在这一个文件里,备份就是复制它
  data\backups\        自动备份:每次启动 + 每次删除操作前都会存一份
  data\gui.log         运行日志,出问题先看这里


【关掉程序】
  直接关窗口即可,进程会跟着退出,不会残留在后台。


【出问题了怎么办】
  1. 打开 data\gui.log 看最后几十行,原因通常已经写在里面
  2. 日志里若没有「[就绪] 窗口已显示」这一行,说明窗口没起来 —— 把日志发我
  3. 数据不会因为启动失败而损坏;实在不行用 data\backups 里的备份覆盖回去
  4. 提示「程序已经在运行了」 —— 到任务栏找那个窗口,或先关掉它
